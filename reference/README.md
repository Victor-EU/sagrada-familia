Reference photographs go here. This directory is gitignored.

Images are used by the photo-match harness at development time only — to verify
that generated geometry matches the real building — and are never bundled into
the build. What ships is numbers.

Twenty-eight of them are here now, 49 MB, inside and out. `SOURCES.md` lists
every one with its author, its licence and a link back to the file page, and says
what each frame is *for* — which is the part that matters when you are looking for
a second viewpoint on a parameter that has only locked against one.

The names are the index. `in-` is interior, `ex-` is exterior, `plan-` is a
drawing, and the rest of the name is the subject: `in-vault-overhead`,
`ex-plaza-nativity`, `in-column-shaft-twist`. Drop one on the window and the
render letterboxes itself to it.
